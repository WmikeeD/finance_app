  🎯 FUNCIONALIDADES IMPLEMENTADAS

  1. Sistema de Breakpoints Material Design 3

  < 600dp   → Mobile (Compact)
  600-840dp → Tablet (Medium)
  > 840dp   → Desktop (Expanded)

  2. Navegación Adaptativa (AppShell)

  - ✅ Mobile (< 600dp): BottomNavigationBar tradicional en la parte inferior
  - ✅ Tablet (600-840dp): NavigationRail lateral colapsado con labels solo en ítem seleccionado
  - ✅ Desktop (> 840dp): NavigationRail extendido con labels siempre visibles

  3. Modales Responsivos con MaxWidth

  Todos los modales de pantallas de datos ahora se limitan a 600dp de ancho en tablets/desktop:
  - ✅ CuentasScreen
  - ✅ CategoriasScreen
  - ✅ PersonasScreen
  - ✅ GastosFijosScreen

  Implementación:
  showModalBottomSheet(
    context: context,
    builder: (_) => ResponsiveHelper.wrapModal(
      context: context,
      child: Screen(),
    ),
  )

  4. Helper Completo de Responsividad

  Métodos disponibles en ResponsiveHelper:
  - isMobile(context), isTablet(context), isDesktop(context)
  - getGridCrossAxisCount() - Para GridView adaptativo
  - getChartHeight() - Alturas adaptativas para gráficos
  - getHorizontalPadding() - Padding horizontal responsivo
  - getContentMaxWidth() - MaxWidth para contenido (600dp en tablets/desktop)
  - wrapModal() - Wrapper automático para modales
  - Extension methods: context.isMobile, context.deviceType

  5. ResponsiveBuilder Widget

  ResponsiveBuilder(
    builder: (context, deviceType) {
      if (deviceType == DeviceType.mobile) {
        return MobileLayout();
      }
      return TabletLayout();
    },
  )
