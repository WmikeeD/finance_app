  2. Layout Dual: Column vs Row 🔄

  MOBILE (< 600dp) - Vertical Stack:

  ┌──────────────────────┐
  │  GASTOS POR CATEG.   │
  ├──────────────────────┤
  │                      │
  │    🥧 PIE CHART     │  ← 200px altura
  │                      │
  ├──────────────────────┤
  │ ● Categoría A  35%  │
  │ ● Categoría B  28%  │  ← Leyenda debajo
  │ ● Categoría C  20%  │
  └──────────────────────┘

  Implementación:
  Column(
    children: [
      SizedBox(height: chartHeight, child: pieChart),
      SizedBox(height: AppSpacing.md),
      _buildCategoryLegend(...),
    ],
  )

  TABLET/DESKTOP (≥ 600dp) - Horizontal Split:

  ┌───────────────────────────────────────────────┐
  │  GASTOS POR CATEGORÍA                         │
  ├────────────────┬──────────────────────────────┤
  │                │  ● Categoría A  $150,000  35%│
  │   🥧 PIE      │  ● Categoría B  $120,000  28%│  ← 300/400px altura
  │    CHART      │  ● Categoría C   $85,000  20%│
  │                │  ● Categoría D   $60,000  14%│
  │    40%         │         60%                  │
  └────────────────┴──────────────────────────────┘

  Implementación:
  Row(
    children: [
      Expanded(flex: 40, child: pieChart),       // 40% izquierda
      SizedBox(width: AppSpacing.lg),
      Expanded(flex: 60, child: legend),         // 60% derecha
    ],
  )

  ANTES:

  5. Eliminación de Colores Hardcoded

  ANTES:
  ❌ Colors.grey[600]          // Texto vacío
  ❌ Colors.white              // Título de sector pie
  ❌ Colors.grey.withValues()  // Grid del BarChart
  ❌ TextStyle(fontSize: 12)   // Tamaños hardcoded

  DESPUÉS:
  ✅ scheme.onSurfaceVariant                    // Texto vacío
  ✅ scheme.onPrimary                           // Título de sector
  ✅ scheme.outlineVariant.withValues(alpha:)   // Grid lines
  ✅ Theme.of(context).textTheme.labelSmall     // Tipografía M3
  ✅ Theme.of(context).textTheme.bodySmall      // Categorías
